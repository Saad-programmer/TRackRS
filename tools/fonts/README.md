# Fonts for offline bakes

Used only by `tools/bake_sahara_signs.py`, which bakes sign text into a PNG
atlas. The game never loads these fonts at runtime.

| `NotoSans-Bold.ttf` | Noto Sans Bold | SIL OFL 1.1 (`OFL.txt`; the Noto project uses the same licence for its Latin fonts) | https://github.com/notofonts/notofonts.github.io (`fonts/NotoSans/hinted/ttf/`) |
