# Content pack `morocco-sahara` — Rallye Sahara Draâ

Fictional rally-raid content over real Moroccan terrain character (amendment
A, `docs/MOROCCO_AMENDMENT.md`). Every file in this pack is covered by an
`assets` entry in `pack.json` with an SPDX licence and an attribution; the
`content-packs-shipped` test fails otherwise. Credits are generated into
`docs/CREDITS.md` by `trackrs-content credits`.

Stages are added gate by gate (M1 test stage, M2 Zagora Prologue, M5 the rest).
