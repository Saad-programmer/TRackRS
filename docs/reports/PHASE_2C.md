# Phase 2c — PBR material pipeline

Gate: verification in progress. Phase 2d has not started.

## Behavior and integration

Existing OBJ/ASE content retains its original loader, materials, core basic
lighting/fog shader, and rendering order. Only imported glTF materials with all
three surface textures (base color, tangent normal, metallic/roughness) select
PBR. Incomplete sets select the legacy renderer; metallic/roughness factors alone
do not silently change existing content.

Appendix A is integrated as `data/shaders/pbr/pbr.vert` and `pbr.frag`, with shared
production BRDF functions in `brdf.glsl`. It includes point lights, clear coat,
normal mapping, instanced transforms and CPU inverse-transpose normal matrices.
Mirrored model transforms retain tangent-frame parity. Tangents use the model's
linear transform, rather than the normal matrix, before Gram–Schmidt correction;
this corrects Appendix A under nonuniform scaling and shear.

CSM hooks accept a borrowed comparison texture array, view matrix, four light
matrices and split depths. A synthetic comparison-map test exercises the hook.
This gate does not generate cascades. Masked materials use alpha-to-coverage on
multisample targets and discard on single-sample targets. IBL shader declarations
remain disabled; no environment maps, baker, probe, KTX2 loader or Phase 2d texture
library has been added.

Appendix B layouts are compile-time checked at every offset: `Vertex` 56 bytes,
`VertexPacked` 32 bytes. Both have retained VAO/VBO/index buffers; instanced model,
normal and parity attributes occupy locations 6–13. The explicit format retains
vertex colors in a separate RGBA8 stream. GL state is restored around the PBR
renderer and the basic renderer's cache is invalidated before returning to it.

The game adapter supplies eye-space matrices and a shared pair of point headlights
for each imported vehicle body and its wheels. The standalone preview uses world
space. CSM callers must supply matrices in the same space as their frame/model.

## Import and fixture

`engine/mesh/MeshImporter` reads glTF/GLB through pinned cgltf and legacy OBJ,
including negative OBJ indices, polygon triangulation and material groups. glTF
node transforms, normalized accessors, embedded/external buffers and PNG/JPEG
images are supported. Reference MikkTSpace operates on corners before deduplication,
so UV/tangent discontinuities survive. meshoptimizer then deduplicates, optimizes
vertex-cache order, overdraw and vertex fetch. Materials and winding survive the
pass. Import budgets and directory-contained external dependencies reject invalid
or oversized input.

The importer is for static triangle glTF meshes: skins, morph targets, Draco,
nontriangle primitives, alternate UV sets and texture transforms are rejected
with diagnostics. OBJ continues to use legacy materials. Existing game OBJ/ASE
loading is intentionally unchanged. Dependency commits and licenses are in
`third_party/phase2c-dependencies.json` and `third_party/PHASE_2C.md`.
Native UBSan caught two upstream MikkTSpace random-pivot rotations that could
shift a 32-bit unsigned value by 32. The marked downstream patch masks that
shift count; the reference tangent calculation is unchanged. Vendor code remains
sanitizer-instrumented, and importer CPU tests halt on UBSan errors.

The original fictional car is `data/vehicles/pbr_test`, generated by
`tools/generate_pbr_fixture.py`, with CC0 geometry/textures and a separately noted
GPL-derived physics configuration. Every car submesh supplies PBR textures.

From a configured build:

```sh
cmake --build --preset linux-release
build/linux-release/bin/material_preview
build/linux-release/bin/trackrs --headless --data-dir data --stage ahead --vehicle pbr_test --frames 1500
```

Preview keys: 0–6 or F1–F7 select lit/albedo/normal/roughness/metallic/AO/tangent-frame views; H toggles
headlights; Escape exits. The preview has dielectric and metal sphere rows at
roughness 0.1, 0.3, 0.5, 0.7 and 0.9, plus the complete car. Installed builds can
use `material_preview --data-dir <installed-data-directory>`.

## Validation

- glslang compiles and links all 16 combinations of explicit/packed bitangents,
  instancing, CSM and alpha-to-coverage. The driver compiles the same 16 combinations.
- The white furnace integrates the actual shared Appendix A direct BRDF with
  4,096 GGX/cosine samples per cell, dielectric/metal surfaces, roughness 0.04–1.0
  and two view angles. Maximum energy: 0.999992, below 1.0 (numerical test allowance: 0.0001).
  Minimum: 0.306958, reflecting the Appendix A single-scattering rough-metal loss.
  This is a direct-BRDF energy test; full IBL furnace validation belongs to 2d.
- Reciprocity uses the same production BRDF; maximum relative error is
  1.42e-7 against a 1e-5 bound. GGX uses a stable denominator near its smooth peak
  and a minimum denominator instead of an additive epsilon that changes the
  normalized distribution. The furnace PDF is evaluated at the sampled reflected
  light direction, avoiding a float reconstruction artifact at roughness 0.04.
- GPU normal-map tests cover a mirrored-UV sphere and planar fixtures, mirrored UVs, both vertex formats, negative scaling,
  shear and one/two-instance submissions. Explicit and packed reference pixels
  agree exactly in this fixture (allowed difference: one RGB8 level; transformed
  CPU/GPU comparison: two levels).
- A four-sample coverage probe resolves a half-coverage normal-debug red value of
  64, against 128 at full coverage. Point-light and CSM comparisons pass with zero
  unexpected KHR_debug errors.
- Appendix C CPU tests verify quad/mirrored/degenerate-UV tangent bases, signed
  packing, exact layout ABI and invalid indices. Importer tests cover material
  groups, optimizer preservation, GLB/external buffers, mirrored nodes, incomplete
  texture fallback, byte/corner budgets and dependency escape rejection.
