01 / THE DRIVELESS MENU. MORE MOMENT.

A rally game
with its boots
on the ground.

TrackRS is about the small decisions that make a big difference: when to brake, where to place a wheel, and how much you can ask from the surface beneath you.

Built as an independent project by Saad AIT YAHIA, TrackRS brings together rally cars, winding routes, and terrain that changes how the car responds. Gravel, mud, snow and rock are more than scenery. They are part of the conversation between you and the road.

    These images come from the project’s own gameplay and UI review reports. The road surface, distant terrain, car, timer, checkpoint counter, minimap and speed display are all part of a live stage.

    GRAPHICS / CURRENT IMPLEMENTATION

    Old-school rally atmosphere, core OpenGL underneath.

    The current renderer uses one OpenGL 3.3-or-later core context and GLSL 330. It keeps the established visual style with directional lighting, specular highlights, exponential fog, terrain detail, alpha cutouts, and ordered transparency. Terrain, vehicles, foliage, weather particles, menus, text and the HUD are submitted through core-profile rendering paths.

    This is a faithful legacy-look renderer, not a PBR pipeline. That distinction matters when describing what the game is today.

    UI / UX IN THE DRIVER'S SEAT

    Keep the important information in view.

    The stage view puts the countdown and elapsed time at the top, checkpoints beside them, the map within reach, and speed/gear in a clear gauge. Menus provide event and stage selection; the vehicle and stage definitions remain part of the underlying game data.

    From the keyboard, I can steer, brake, change camera, check the map, pause, or recover without leaving the stage.

    All gallery images are linked to their original report files in docs/reports; they are project evidence, not newly staged promotional renders.

    06 / MY FIELD NOTESWALKTHROUGH · BUILD NOTES · EXPERIENCE

    Notes from
    the road.

    I’m sharing the route the way I experience it: first learn the controls, then read the stage, then look back at how the game is built. These are my working notes, grounded in the current demo and the project reports.

    01 / WALKTHROUGH

    My first run: Ahead

    1. I start with the Ahead stage, the route available in the demo.
    2. I use the minimap and checkpoint counter to keep my bearings while the stage timer runs.
    3. I ease into steering and braking instead of treating every surface like tarmac; the vehicle simulation accounts for terrain friction and wheel contact.
    4. If I lose the line, I use R to recover or Q to return to the previous checkpoint, then keep learning the route.

    My goal on a first run is not a perfect time. It’s to understand how the road, controls and pace fit together.

    02 / WHAT I WATCH

    Small signals, useful feedback

    I keep an eye on elapsed time and the target, checkpoint progress, the minimap, and the speed/gear readout. A stage is easier to read when I make one adjustment at a time: brake earlier, settle the steering, then build speed again.

    The game includes multiple camera views, keyboard remapping, and joystick/wheel support in the project. I can change camera with C and toggle the map with M.

    03 / TECHNICAL JOURNAL

    How I’m carrying the visuals forward

    My renderer notes are about preserving the familiar game while removing compatibility-only graphics calls. The current core renderer batches UI and scene geometry, keeps vehicle meshes on the GPU, and draws dust, rain and snow as instances. I use the report screenshots and replay checks to verify that those changes still look like TrackRS.

    What is included in the demo?

    The current demo build unlocks the Ahead single-race route. Other events, practice races and maps remain locked in this build; the wider map and vehicle counts describe the game data, not demo access.

    What are the default controls?

    Arrow keys drive and steer, Space is the handbrake, C changes camera, M toggles the map, R recovers the car, Q recovers to the previous checkpoint, and P pauses.

    What is the license?

    TrackRS is released under GNU GPL version 2. Some bundled game data has separate authors and license terms; check DATA_AUTHORS.txt in the source repository.
