### 1. Linux Installer (`.deb`)

### 2. Windows Installer (`.nsi`)
I created [installer.nsi](file:///home/alan/Downloads/Dev_Game/trackRS/installer.nsi), a Nullsoft Scriptable Install System (NSIS) script. 
* **Installer Compilation:** Once you compile the Windows binary of the game (`trackrs.exe`) and place it with its dependent `.dll` libraries inside the `bin/` directory, you can right-click the `installer.nsi` script on Windows and compile it with NSIS to generate a single-file installer `trackrs-demo-setup.exe`.
* **Features:** Copying files/data recursively, Desktop and Start Menu shortcut generation, and full integration with the Windows Add/Remove Programs registry for clean uninstallation.
